# Technical Support

> Demo University is a fictional university created for this portfolio project. All values below are demo data.

## Common Questions

### What are the file upload limits?
Maximum 10 MB per file. Allowed types: PDF, JPG, PNG, DOCX.

### A form gives an error when I submit.
Do not submit repeatedly, which can create duplicate requests. Note the exact error text and time, then try one more time in a private window. If it fails again, send those details to IT Support.

### A page will not load or looks broken.
Refresh once, try a private window, then another supported browser (latest two versions of Chrome, Edge or Firefox). Check https://status.demo-university.example for known outages.

### My browser shows a security warning on a university site.
Do not bypass the warning. Report the site address and a screenshot to IT Support.

## What to send IT Support
Service name, what you were trying to do, exact error, time, browser and device, and steps already tried. Never send passwords or codes.

## Priority
- **Urgent (same business day):** live exam access failure, payment page failure near a deadline, security warning.
- **Normal (within 1 business day):** everything else.

## Escalate to a human when
- the problem persists after browser/device checks;
- it blocks an exam, payment or enrollment deadline;
- it looks like a security issue.
